# King Carlos Maale — Portfolio

A modern developer portfolio built with Next.js, TypeScript, Tailwind CSS and React.

## Requirements

- Node.js 18.18+ (Node 20+ recommended)
- npm

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Customize

Edit `components/Portfolio.tsx` to change:
- name / introduction
- projects
- skills
- education
- social links
- email

Replace the placeholder GitHub, LinkedIn and email links with your real accounts.

## Production build

```bash
npm run build
npm start
```
